## Family site

The trip information is published as a static website for family, with a map, a page per day, and offline reading on phones. Once GitHub Pages is set up it is at <https://bwbensonjr.github.io/travel/>. It is built from the trip data by [`site/`](site/README.md):

```bash
uv run site/build.py
```
